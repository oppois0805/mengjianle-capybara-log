# 猛健樂紀錄設計資產

## 資料夾

- `images/`：原始 UI/UX 設計稿與視覺參考。
- `demo/`：可直接以瀏覽器開啟的互動式 HTML Demo。

## 已確認的體重功能

- 紀錄頁新增第三個「體重紀錄」分頁，延續施打與購買表單的視覺規則。
- 體重紀錄包含測量日期、測量時間、體重公斤與選填備註。
- 首頁加入體重與施打趨勢組合圖。
- 日期使用 X 軸；體重使用左側 Y 軸折線；施打時間使用右側 Y 軸直條。
- 圖表提供週、月、年三種期間切換。
- 手機為主要版型，電腦版延續左側導覽與資訊面板配置。
- 文文與豪豪的體重資料分開儲存與顯示。

## Demo

開啟 `demo/mengjianle-weight-concept.html`，可切換手機首頁、體重紀錄與電腦首頁，並操作週、月、年圖表期間。
